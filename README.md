# ASF-RandomBotFriends

Плагин для **[ArchiSteamFarm](https://github.com/JustArchiNET/ArchiSteamFarm)**, который периодически рассылает случайные заявки в друзья от имени ваших ботов.

Каждому боту при первом запуске назначается случайная цель по количеству друзей в диапазоне `[MinFriends; MaxFriends]`. Пока текущее количество друзей у бота меньше цели, плагин раз в `DelayBetweenInvites` секунд выбирает случайного бота, которому есть кому написать, и отправляет заявку одному случайному кандидату из включённых источников. За один тик отправляется не более одной заявки на весь инстанс — это и есть задержка между инвайтами.

Источники кандидатов (можно включить один или оба):

- **Другие боты этого ASF** (`InviteOwnBots`, включён по умолчанию) — bot-to-bot, безобидно, все аккаунты ваши.
- **Комментаторы из групп, в которых бот уже состоит** (`InviteGroupCommenters`, выключен по умолчанию) — плагин берёт случайную группу из тех, где бот реально состоит участником, читает последние `CommentsToScan` комментариев на стене группы и предлагает в друзья случайному автору комментария. На практике в такой пул чаще всего попадают люди, сами написавшие в комментариях что-то вроде "add me" — но это всё равно **заявки незнакомым живым людям**, а не вашим ботам. Это заметно более узнаваемый для Steam паттерн бот-поведения, чем bot-to-bot дружба, и увеличивает риск ограничений на аккаунт сильнее, чем остальные плагины серии. Включайте осознанно.

## Установка

1. Скачайте архив плагина из [Releases](../../releases) и распакуйте в папку `plugins` рядом с ASF (создайте подпапку с именем плагина).
2. Перезапустите ASF.

## Конфигурация

Настройки задаются **глобально**, в `ASF.json`, как дополнительные (нераспознанные ASF) свойства верхнего уровня:

```json
{
	"RandomBotFriendsEnabled": true,
	"RandomBotFriendsMinFriends": 2,
	"RandomBotFriendsMaxFriends": 5,
	"RandomBotFriendsDelayBetweenInvites": 60,
	"RandomBotFriendsInviteOwnBots": true,
	"RandomBotFriendsInviteGroupCommenters": false,
	"RandomBotFriendsCommentsToScan": 50
}
```

| Свойство | Тип | По умолчанию | Описание |
| --- | --- | --- | --- |
| `RandomBotFriendsEnabled` | `bool` | `false` | Включает/выключает плагин. |
| `RandomBotFriendsMinFriends` | `byte` (0-255) | `2` | Нижняя граница случайной цели по числу друзей для каждого бота. |
| `RandomBotFriendsMaxFriends` | `byte` (0-255) | `5` | Верхняя граница случайной цели по числу друзей для каждого бота. |
| `RandomBotFriendsDelayBetweenInvites` | `ushort`, секунды | `60` | Пауза между отправкой заявок в друзья (одна заявка за тик на весь инстанс ASF). |
| `RandomBotFriendsInviteOwnBots` | `bool` | `true` | Источник кандидатов: другие боты этого ASF. |
| `RandomBotFriendsInviteGroupCommenters` | `bool` | `false` | Источник кандидатов: авторы последних комментариев в группах, где бот уже состоит участником. См. предупреждение выше. |
| `RandomBotFriendsCommentsToScan` | `byte` (1-100) | `50` | Сколько последних комментариев группы читать за один запрос, если `InviteGroupCommenters` включён. |

Если оба источника выключены, плагин один раз пишет предупреждение и ничего не делает. Если `MinFriends` больше `MaxFriends`, значения меняются местами автоматически. Заявки отправляются только тем, с кем ещё нет никаких отношений (не друг, заявка не отправлена/не получена, не заблокирован), и никогда — самому себе или другим ботам этого же ASF через источник комментариев. Цель по числу друзей при включённом только `InviteOwnBots` физически ограничена количеством остальных ботов в этом же ASF — если `MinFriends` больше, чем `количество ботов − 1`, плагин один раз выведет предупреждение в лог.

## Сборка

Проект использует **[ASF-PluginTemplate](https://github.com/JustArchiNET/ASF-PluginTemplate)** и собирается вместе с исходниками ASF, подключёнными как git submodule:

```sh
git clone --recurse-submodules https://github.com/buddymurdock/ASF-RandomBotFriends.git
cd ASF-RandomBotFriends
dotnet build -c Release
```

Если репозиторий уже склонирован без `--recurse-submodules`, подтяните submodule отдельно:

```sh
git submodule update --init --recursive
```
