# ASF-RandomBotFriends

Плагин для **[ArchiSteamFarm](https://github.com/JustArchiNET/ArchiSteamFarm)**, который периодически рассылает случайные заявки в друзья от имени ваших ботов.

Плагин раз в `DelayBetweenInvites` секунд выбирает случайного бота, которому есть кому написать, и отправляет заявку одному случайному кандидату из включённых источников. За один тик отправляется не более одной заявки на весь инстанс — это и есть задержка между инвайтами.

Источники кандидатов (можно включить один или оба) — у каждого **своя независимая цель по количеству друзей и свой диапазон**, назначаемый случайно каждому боту при первом обращении:

- **Другие боты этого ASF** (`InviteOwnBots`, включён по умолчанию, цель — `[OwnBotsMinFriends; OwnBotsMaxFriends]`) — bot-to-bot, безобидно, все аккаунты ваши.
- **Комментаторы из групп, в которых бот уже состоит** (`InviteGroupCommenters`, выключен по умолчанию, цель — `[GroupCommentersMinFriends; GroupCommentersMaxFriends]`) — плагин берёт случайную группу из тех, где бот реально состоит участником, читает последние `CommentsToScan` комментариев на стене группы и предлагает в друзья случайному автору комментария. На практике в такой пул чаще всего попадают люди, сами написавшие в комментариях что-то вроде "add me" — но это всё равно **заявки незнакомым живым людям**, а не вашим ботам. Это заметно более узнаваемый для Steam паттерн бот-поведения, чем bot-to-bot дружба, и увеличивает риск ограничений на аккаунт сильнее, чем остальные плагины серии. Включайте осознанно.

Цели разделены специально: количество друзей среди своих ботов и количество добавленных незнакомцев из групп считаются и ограничиваются независимо друг от друга (плагин смотрит, кому именно принадлежит каждый принятый/исходящий SteamID — своему боту или нет). Так можно, например, держать `OwnBotsMaxFriends` высоким, а `GroupCommentersMaxFriends` — низким, не смешивая риск-профили этих двух источников в одном счётчике.

## Установка

1. Скачайте архив плагина из [Releases](../../releases) и распакуйте в папку `plugins` рядом с ASF (создайте подпапку с именем плагина).
2. Перезапустите ASF.

## Конфигурация

Настройки задаются **глобально**, в `ASF.json`, как дополнительные (нераспознанные ASF) свойства верхнего уровня:

```json
{
	"RandomBotFriendsEnabled": true,
	"RandomBotFriendsDelayBetweenInvites": 60,
	"RandomBotFriendsInviteOwnBots": true,
	"RandomBotFriendsOwnBotsMinFriends": 2,
	"RandomBotFriendsOwnBotsMaxFriends": 5,
	"RandomBotFriendsInviteGroupCommenters": false,
	"RandomBotFriendsGroupCommentersMinFriends": 1,
	"RandomBotFriendsGroupCommentersMaxFriends": 3,
	"RandomBotFriendsCommentsToScan": 50
}
```

| Свойство | Тип | По умолчанию | Описание |
| --- | --- | --- | --- |
| `RandomBotFriendsEnabled` | `bool` | `false` | Включает/выключает плагин. |
| `RandomBotFriendsDelayBetweenInvites` | `ushort`, секунды | `60` | Пауза между отправкой заявок в друзья (одна заявка за тик на весь инстанс ASF). |
| `RandomBotFriendsInviteOwnBots` | `bool` | `true` | Источник кандидатов: другие боты этого ASF. |
| `RandomBotFriendsOwnBotsMinFriends` | `byte` (0-255) | `2` | Нижняя граница случайной цели по числу друзей-ботов для каждого бота. |
| `RandomBotFriendsOwnBotsMaxFriends` | `byte` (0-255) | `5` | Верхняя граница случайной цели по числу друзей-ботов для каждого бота. |
| `RandomBotFriendsInviteGroupCommenters` | `bool` | `false` | Источник кандидатов: авторы последних комментариев в группах, где бот уже состоит участником. См. предупреждение выше. |
| `RandomBotFriendsGroupCommentersMinFriends` | `byte` (0-255) | `1` | Нижняя граница случайной цели по числу друзей-незнакомцев из групп для каждого бота. |
| `RandomBotFriendsGroupCommentersMaxFriends` | `byte` (0-255) | `3` | Верхняя граница случайной цели по числу друзей-незнакомцев из групп для каждого бота. |
| `RandomBotFriendsCommentsToScan` | `byte` (1-100) | `50` | Сколько последних комментариев группы читать за один запрос, если `InviteGroupCommenters` включён. |

Если оба источника выключены, плагин один раз пишет предупреждение и ничего не делает. Если `MinFriends` больше `MaxFriends` в любой из пар, значения меняются местами автоматически. Заявки отправляются только тем, с кем ещё нет никаких отношений (не друг, заявка не отправлена/не получена, не заблокирован), и никогда — самому себе или другим ботам этого же ASF через источник комментариев. Цель `OwnBotsMinFriends` физически ограничена количеством остальных ботов в этом же ASF — если она больше, чем `количество ботов − 1`, плагин один раз выведет предупреждение в лог.

> Начиная с этой версии `RandomBotFriendsMinFriends`/`RandomBotFriendsMaxFriends` (из версии 1.1.0.0) переименованы в `RandomBotFriendsOwnBotsMinFriends`/`RandomBotFriendsOwnBotsMaxFriends` — если у вас уже настроен `ASF.json` со старыми именами, переименуйте свойства.

Важно: в цель (`target`) засчитываются не только принятые заявки, но и уже отправленные, но пока не принятые (`RequestInitiator`) — это тормоз, особенно важный для источника комментариев. Незнакомцы чаще всего не принимают заявки от ботов, и без этого правила бот слал бы заявки бесконечно, потому что "текущих друзей" по факту всегда меньше цели. С этим правилом бот один раз выбирает до `target` кандидатов и замолкает, даже если никто не ответил. На источник комментариев дополнительно наложено ограничение — не более одного запроса к steamcommunity.com за тик, независимо от того, сколько ботов проверяется в рамках этого тика.

## Сборка

Проект использует **[ASF-PluginTemplate](https://github.com/JustArchiNET/ASF-PluginTemplate)** и собирается вместе с исходниками ASF, подключёнными как git submodule:

```sh
git clone --recurse-submodules https://github.com/buddymurdock/ASF-RandomBotFriends.git
cd ASF-RandomBotFriends
dotnet build -c Release
```

Если репозиторий уже склонирован без `--recurse-submodules`, подтяните submodule отдельно:

```sh
git submodule update --init --recursive
```
